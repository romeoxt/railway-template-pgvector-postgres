Vector search in Postgres.
No separate database.

Deploy PostgreSQL 17 with pgvector on Railway. Store embeddings, run similarity queries, and connect your RAG API over private networking.

DEPLOY ON RAILWAY 
CREATE EXTENSION vector;

CREATE TABLE docs (
  id bigserial PRIMARY KEY,
  content text,
  embedding vector(1536)
);

SELECT content
FROM docs
ORDER BY embedding <=> $1
LIMIT 5;
